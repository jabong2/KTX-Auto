# KTX Agent prototype
Android Studio에서 이 폴더를 열고 JDK 17, Android SDK 35를 설치한 후 Build > Build APK(s). Gradle 8.9 사용. Gradle wrapper는 포함하지 않았습니다.
코레일톡 이용약관에서 자동화 허용 여부를 확인한 후에만 사용하세요. 접근성 권한을 활성화하고 코레일톡에서 KTX만 조회한 뒤 감시를 시작하세요. 화면을 켜고 잠금을 해제해야 합니다. 30초 간격 재조회는 정확한 버튼 문구가 노출될 때만 수행합니다. 예약 클릭 후에는 결과 문구를 기다리며 추가 클릭하지 않습니다. 결과가 불명확하면 수동 확인 후 감시를 재시작하세요. 성공 후 중복 예약 방지를 위해 종료 옵션을 꺼도 자동 재예약하지 않습니다. 결제 및 보안장치 우회는 구현하지 않았습니다.
실제 코레일톡 접근성 트리와 빌드 테스트를 수행하지 못했습니다. 버튼 문구, 패키지명, 결과 화면 판별은 검증 및 수정이 필요합니다. 플로팅 제어창은 미구현입니다. 전체 열차는 현재 화면에서 접근성으로 노출된 예약 버튼만 의미하며 스크롤 탐색은 미구현입니다. KTX 전용 조회를 사용해야 합니다. 예약 완료 문구 감지는 실제 예약 성공을 보증하지 않습니다.
